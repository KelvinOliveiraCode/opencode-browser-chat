OpenCode Chat Flutuante

Chat com seus modelos do OpenCode direto no navegador, com menu de pre-prompts na seleção e as suas skills como base.

Servidor OpenCode

Normalmente 127.0.0.1. Não use host remoto.
A porta que você passou em opencode serve --port.
Definida por OPENCODE_SERVER_PASSWORD ao iniciar o servidor. Guardada só neste navegador.
As sessões do chat ficam vinculadas a esta pasta. Não precisa existir.

Modelo padrao

O quanto o modelo pensa antes de responder. Mais alto = resposta melhor e mais lenta. O que estiver marcado aqui vale para toda conversa nova.
Sem visao o botao ver tela fica desabilitado no painel.

Modelo de visao

Marcado: a imagem anexada vai direto para o modelo de texto — ele precisa enxergar imagem. Desmarcado: entra em cena um segundo modelo so para a visao.
Baixo costuma bastar: aqui a tarefa é descrever o que esta na tela, nao raciocinar sobre isso.
Como funciona a diferenca: com um modelo so, voce manda a imagem e ele responde. Com dois, a imagem vai primeiro para o que enxerga, que devolve uma descricao; essa descricao entra como contexto no prompt do modelo de texto, que responde sem nunca ver a imagem. Util quando o modelo que voce prefere para conversar nao tem visao — e tambem quando o de visao e melhor descrevendo do que raciocinando.

Comportamento

Arraste para mover. Clique abre o chat. Duplo clique devolve ao canto.

Instalar no Windows

Rode o script server\start.ps1 para subir o servidor com a senha acima. Depois carregue a pasta extension em brave://extensions → Modo de desenvolvedor → Carregar sem compactação.

powershell -ExecutionPolicy Bypass -File server\start.ps1
